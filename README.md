# 단체티 사이즈 조사 앱

학생이 **학년 → 반 → 번호 → 이름**을 순서대로 입력하고 **S~4XL** 중 사이즈를 눌러 제출하면,
선생님 화면에서 **전체 명단(학년·반·번호 순)**, **학년별 사이즈별 인원**, **전교 사이즈별 인원**을 볼 수 있습니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (GitHub Pages에 올리는 파일) |
| `Code.gs` | 구글 시트에 응답을 모으는 Apps Script |

---

## 1. 구글 시트 연결 (여러 학생이 각자 휴대폰으로 응답할 때 필수)

GitHub Pages는 저장 공간이 없어서, 응답은 구글 시트에 모읍니다.

1. 구글 시트를 새로 만듭니다. (예: `단체티 사이즈 조사`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기존 코드를 지우고 `Code.gs` 내용을 붙여넣습니다.
4. 맨 위 `ADMIN_KEY = '1234'`를 선생님만 아는 비밀번호로 바꾸고 저장합니다.
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
6. 권한 승인 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. `index.html` 아래쪽 `CONFIG`의 `API_URL: ""` 따옴표 안에 붙여넣습니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 2. GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. (예: `tshirt-size`)
2. `index.html`을 업로드합니다. (`Code.gs`, `README.md`는 올려도 되고 안 올려도 됩니다)
3. **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://아이디.github.io/tshirt-size/` 주소로 접속됩니다. 이 주소를 QR코드로 만들어 배포하세요.

> 저장소가 공개(Public)면 `index.html` 내용도 공개됩니다. 비밀번호는 `Code.gs`(구글 쪽)에만 있으므로 명단은 안전합니다.

## 3. 사용법

- **학생**: 주소 접속 → 학년 버튼 → 반 → 번호 → 이름 → 사이즈 카드 클릭 → 제출
  - 같은 학년·반·번호로 다시 제출하면 새 사이즈로 **덮어쓰기**(중복 방지)
- **선생님**: 오른쪽 위 `선생님용` → 비밀번호 입력
  - 새로고침, 학년 필터, 응답 삭제(두 번 클릭), 엑셀(CSV) 저장, 인쇄
  - 구글 시트 `응답` 탭에서도 원본을 바로 확인·수정할 수 있습니다.

## 4. 설정 바꾸기 (`index.html`의 CONFIG)

| 항목 | 설명 |
|---|---|
| `TITLE`, `BRAND` | 화면 제목 |
| `GRADES` | 학년 선택지 (예: `[1,2,3]`) |
| `MAX_CLASS`, `MAX_NO` | 반, 번호 최댓값 |
| `SIZES` | 사이즈 목록과 보조 표기. 예: `["XS","85"]`를 맨 앞에 추가 가능. 보조 표기가 필요 없으면 `""` |
| `LOCAL_PIN` | `API_URL`이 비어 있을 때(이 기기 저장 모드) 관리자 비밀번호 |

## 참고: 이 기기 저장 모드

`API_URL`을 비워 두면 응답이 **그 기기의 브라우저에만** 저장됩니다.
교실 태블릿 한 대를 돌려가며 받는 경우에만 쓰고, 여러 기기 응답은 반드시 구글 시트를 연결하세요.
